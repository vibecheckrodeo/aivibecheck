The brand comparison uses the approved Butter identity plus 12 distinct
directions from the last three archived four-option sheets (13 styles total).

butter-wordmark.png: unmodified copy of the current production logo
four-eye-serif-wave-conversation-options.png: unmodified copy of the identically
named file in logos/archive/; Eye, Expressive serif, Ribbon, Conversation.
four-slop-cleanup-options.png: unmodified copy of the identically named file in
logos/archive/; Splash check, Melting type, Peel back, Sifted slop.
four-serious-typographic-options.png: unmodified copy of the identically named
file in logos/archive/; Geometric, Editorial, Condensed, Humanist.

SVG viewports and clip paths isolate each original direction. The clipping
excludes option numbers, dividers and small embedded slogans. Splash check and
Peel back use notched clip boundaries to retain the left-side illustration
while excluding the slogan below the wordmark. No raster artwork was edited.

One sheet is loaded only when one of its four directions is selected. Already
loaded sheets are reused; the currently visible artwork remains until the
new SVG image reports success. Butter requires no alternate sheet download.

Page colors approximate each concept's ink, accent and paper. Heading fonts
use related system families, not claimed exact matches to the unnamed source
fonts. Body and form typography stays unchanged. The original Butter palette
and Georgia headings remain the default.
