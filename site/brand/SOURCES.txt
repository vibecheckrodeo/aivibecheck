Four shortlisted themes: Butter, Geometric, Ribbon, Expressive serif.

butter-solid-k.png: built-in image-editing tool revision of butter-wordmark.png.
Edit prompt: make the peach strokes of the lowercase k solid dark teal #084E50;
retain the remaining lettering, i dot, separate V/check accent, and background.
The original butter-wordmark.png remains archived without modification.

Geometric is clipped from four-serious-typographic-options.png.
Ribbon and Expressive serif are clipped from
four-eye-serif-wave-conversation-options.png. Both are unmodified copies of
the identically named sheets in logos/archive/. SVG viewports and clipping
exclude option numbers, dividers and embedded slogans. Other original brand
sheets remain archived, but their directions are no longer selectable.

A sheet is requested only when a shortlisted direction needs it. The current
style remains visible until the new SVG image loads; failed loads retain the
visible style. Butter does not need an alternate sheet.

Supported query IDs: butter, geometric, ribbon, expressive-serif.
Successful selection writes theme as the final URL query parameter with
history.replaceState, preserving other parameters and the fragment. The
keyboard shortcut Ctrl+Shift+K cycles the four themes without navigation or
replacing form fields. The copied URL opens that exact style, as do ad links.

Ordinary visits exclude the last successfully displayed style when local
storage is available. History state marks automatically selected URLs so
refresh can rotate again, while a copied URL or shortcut choice is pinned.
Missing, retired or invalid theme IDs use normal random selection. Failed
artwork never commits an unseen style to storage or the address bar.

Page colors approximate the original concepts; heading fonts use related
system families, not exact matches to the unnamed fonts. Body and form
font styling is unchanged. Butter remains the no-script/loading fallback.

serif-palettes.webp and other original sheets are retained for cached older
pages. They are not requested by the current theme rotation.
